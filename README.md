# Studio Devastante

Sito di Studio Devastante, lo studio fotografico di Nicola Perantoni.
**→ [devastante.studio](https://devastante.studio)**

Astro · TypeScript · GSAP · Vercel

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # sito statico in dist/
```

- Testi (italiano e inglese) e percorsi: [`src/i18n/ui.ts`](src/i18n/ui.ts)
- Foto della Home: [`src/data/photos.ts`](src/data/photos.ts) e `src/assets/photos/`
- Dominio: `site` in [`astro.config.mjs`](astro.config.mjs) e `public/robots.txt`

Push su `main` → deploy automatico su Vercel.
